Iron Peak Fitness Website

# Overview

Iron Peak Fitness is a responsive multi-page gym website developed using HTML, CSS, JavaScript and jQuery. The website promotes a fictional gym business by showcasing memberships, fitness classes, personal trainers, supplements and contact information.


# Features

- Responsive website design
- Multi-page navigation
- Homepage image slideshow using JavaScript
- Personal Trainers page
- Membership page
- Fitness Classes page
- Supplements page
- Contact page
- User Sign Up page
- Search and filter functionality on the Supplements page
- Interactive buttons and hover effects


# Technologies Used

- HTML
- CSS
- JavaScript
- jQuery
